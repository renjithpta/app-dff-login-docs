# AOBP BFF Architecture Package

Open `AOBP_BFF_Centralized_SSO_Architecture.md` in a Markdown editor with local-image support.

- `images/`: seven redrawn PNG diagrams, each 3408 pixels wide.
- `svg/`: matching vector SVGs for scaling and presentation use.
- `diagram-source/`: editable Mermaid source with matching flow semantics and numbering; layouts may differ between renderers.

Keep the folder structure intact so relative image links work. The Markdown preserves the PDF section content, tables, security mitigations, owners, residual risks and references. PDF page headers, footers and page breaks are omitted.

The diagrams describe an architecture, not evidence of completed runtime or penetration tests. Microservice 1 and Microservice 2 are generic examples. The public edge and provider redirect hops omitted from individual sequence diagrams are explained in their captions.
